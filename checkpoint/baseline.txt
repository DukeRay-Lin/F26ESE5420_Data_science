# Can one-hot encoding make linear regression match an MLP?

## Group

## Changes since the proposal
Per instructor feedback, C+ will be added and B+ included in the main comparison; neither is implemented yet. A/B baselines are completed. The fixed date split yields 13,891/3,488 records rather than the proposed 13,903/3,476.

## Data
UCI Bike Sharing hour.csv contains 17,379 hourly records from 2011–2012. The target is cnt. Twelve inputs are used: season, yr, mnth, hr, holiday, weekday, workingday, weathersit, temp, atemp, hum, and windspeed. No rows were deleted. Three weathersit=4 records were mapped to 3. Identifiers and target-leakage columns are excluded; dates remain evaluation metadata. The original CSV is unchanged.

## Split
Train: 13,891 records before 2012-08-07. Final held-out test: 3,488 records from that date onward. A/B use five expanding-window CV folds with complete-date validation windows, earlier training dates, and no shuffling. Preprocessing is fitted within each fold. Bootstrap seed: 42. The final test set remains untouched.

## Baseline
Model B uses Ridge with one-hot encoding of hr, weekday, mnth, season, and weathersit. The remaining seven predictors are standardized within each training fold. A logarithmic grid of 25 alpha values from 10^-4 to 10^4 was evaluated using five-fold CV. Minimum mean validation MAE selected alpha=0.0001. Model A uses standardized numerical inputs with ordinary LinearRegression.

## Result
Model B pooled out-of-fold Validation MAE is 80.1873 bikes/hour, with a 95% bootstrap CI of [78.2162, 82.2004], computed from 5,000 whole-day resamples stratified by fold. Model A OOF MAE is 108.7474. Each model generated 11,608 validation predictions. These are CV validation results, not final test scores.

## Issues found
The proposal's split counts were incorrect. The dataset omits 165 hourly timestamps, which were not imputed. Early CV folds contain unseen month categories, potentially disadvantaging one-hot models. The selected alpha lies at the grid's lower boundary. Reusing CV for tuning and scoring introduces possible optimism; the bootstrap CI excludes tuning and retraining uncertainty.

## Next steps

For subsequent experiments, we will revise the shared expanding-window CV: initial training will cover all of 2011 and January 2012, followed by five validation windows from February through August 6, 2012. This ensures all calendar months and both years appear in initial training. All models will be reevaluated under the same revised folds; the final test set remains untouched.
